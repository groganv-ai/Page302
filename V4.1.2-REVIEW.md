# Page302 v4.1.2_003

Branch `v4.1.2_003` starts from approved `origin/main` at `f33dad1` and includes the prior testing release `v4.1.1_003` (`fef3ee9`). Main and the original checkout are unchanged. This branch is for review; no deployment is authorized.

## Working input

Select a club and an open Team row, then enter a surname. The existing matching, disambiguation, duplicate checks and scoring functions process the answer. Full typed position/surname/club input is retired at the user's request. Both selections clear after success; wrong answers keep them. Incomplete selections or an empty surname show guidance without counting a guess. Every validly formed attempt counts once, including one that requires a name choice.

Selections toggle off when clicked again or cleared using their chips. Input remains enabled before selections and uses a grey Answer label/ball; selecting both turns them white and scrolls/focuses the surname field. Each selected step disappears from the cyan hint.

The exact selected row is filled. Saved picks now include optional row metadata; new saves recover the selected rows, and prior saves without row metadata retain the previous sequential recovery behaviour. Score submission payloads, retry identity, scoring and backend endpoints are unchanged from v4.1.1.

## Presentation

Clubs left, Team right; existing responsive stacking breakpoint retained. Club Usage is left of Player Rarity and above it when stacked. Club codes are removed from the Clubs list. Both lists use centred, single-line names with equal whole white dash padding; text scales down only when needed to fit. Selected rows show cyan with `>` and `<` markers and hide dashes. Team entries retain club codes, followed by `x` and the rarity. Labels use the existing club-use and rarity colours, and the last accepted Team row and submitted club are bold. Manager spacing remains distinct.

The agreed introduction, pink RAREST, Answer colon, feedback animations, error colours, BONUS labels and shortened seasons are retained. Help describes the new selection flow. There are no fixed Čech entries, generated teams, design controls or submission overrides in this release.

## Review

Local review: set `PORT=8088` and run `node tools/v4-review.cjs`, then open `http://127.0.0.1:8088/`. Scores and report fixtures remain in process memory. The existing design prototypes remain on port 8087 separately.

Release requires review before pushing/merging. Deployment and backend rollout still require separate explicit approval.
